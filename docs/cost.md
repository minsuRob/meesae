# 비용 메모

- **전화 인증 SMS**: 2024년 9월부터 무료 한도 없음. Blaze 필수, 건당 국가별 과금(한국 약 $0.03 수준 — 공식 가격표 재확인).
  SMS 지역 정책으로 서비스 국가만 열고, 인증은 "추가 권한"이라 전원이 하지 않는다. 개발은 에뮬레이터라 0원
- **Functions**: 모든 쓰기가 Functions 를 지나므로 호출 수가 곧 비용. 리전 asia-northeast3, maxInstances 10
- **Firestore**: 추천 1회 = 후보 60건 + 비공개 문서 getAll + 좋아요 getAll. 사용자가 늘면 후보 수·캐시 재검토
- **Storage**: 업로드마다 트리거가 1600px JPEG 로 다시 저장 (원본보다 작아진다)
- **지오코딩**: Nominatim 무료(정책 제한). geohash 6자리 셀 캐시로 같은 동네는 다시 부르지 않는다.
  언어 수만큼 추가 호출이 생긴다 (지금 ko·en + 현지 = 셀당 최대 3회)
- **지도 타일**: OpenFreeMap 무료
- 예산 알림: Google Cloud 결제 → 예산 및 알림에서 월 한도를 걸어 둔다
