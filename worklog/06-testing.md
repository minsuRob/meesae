## 검증 안 된 것

- **네이티브 iOS/Android 전부** (빌드 자체를 안 해 봄)
- 휴대폰 인증 실제 문자, 실시간 위치공유(시작·갱신·종료), 프로필 수정, 국가 변경, 차단 해제,
  신고 5회 자동 숨김, 게시물 삭제, 슈퍼라이크, 추가 필터 아이템, 만료 정리 스케줄러, 추천 '같은 구/시·도' 범위·다음 페이지
- 화면: 사진 선택 창(자동화 불가), 필터 시트, 글쓰기 사진 첨부, 설정의 탈퇴 버튼
- 브라우저 패널 제약: 제 클릭으로 연 로그인 팝업과 위치 권한은 막힌다 → 그 단계는 사람이 직접
