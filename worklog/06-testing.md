### 검증 세션 (2026-10-12, 같은 브랜치)

웹(에뮬레이터, 신규 dev 계정 `qa1`, 데스크톱 폭 ≈800px 다크 → 설정에서 라이트로 전환):
- 온보딩 9단계 끝까지(사진 3장 업로드는 파일 입력에 JS 로 이미지 주입, 위치는 권한 거부 안내 → 건너뛰기, 마지막 국가) → 포인트 50P 보상
- 추천 → 필터 시트(여성 적용·초기화) → 좋아요 → 대화하기 → 메시지 전송(밝은 말풍선) → 메뉴 시트·신고 사유 시트 → 피드 글쓰기 시트(사진 추가) → 글 상세 댓글
- 포인트: 출석(+10P·토스트·완료 상태), 상점 슈퍼라이크 구매(확인창 모킹, 60→30P, 1개 보유), 설정(화면 모드·언어·국가 시트, 라이트 전환), 휴대폰 인증(에뮬레이터 로그 코드, +100P)
- 375px: 추천·피드·설정·`/dev/ui` 가로 넘침 0. 이후 브라우저 패널이 숨겨져 캡처가 막혀, 375px·라이트의 나머지 화면은 눈으로 못 봄
- 확인 못 한 것: 채팅 잠금 아이콘·구매 확인창은 `window.confirm` 이라 캡처에 안 잡힘(로직만 확인), 로그아웃, 데스크톱 1024 폭 캡처

네이티브:
- iOS 시뮬레이터(iPhone 17 Pro, Release 빌드, 에뮬레이터 백엔드): Pretendard 3종이 번들·`UIAppFonts` 에 들어가고 실제로 렌더, 탭바가 홈 인디케이터 위에 놓임, 필터 시트·추천 라이트·다크, 다크 런치 화면이 검은 배경(흰 번쩍임 없음). 화면 키보드는 여전히 안 떠서 시트 키보드 가림은 못 봄 (I/O › Keyboard 토글로도 안 뜸)
- Android 에뮬레이터(API 36, Release APK): Pretendard 렌더, 온보딩에서 키보드가 올라오면 하단 '다음' 버튼이 키보드 위로 올라오고 포커스 입력란이 보임 (keyboard-controller 경로). 로그인 화면의 개발용 입력칸은 `scroll` 이 없어 키보드에 가림 — 실서비스(구글·애플 버튼만)에는 입력칸이 없어 영향 없음
- 못 본 것: 햅틱(시뮬레이터로 확인 불가), Android 다크 스플래시·시트 키보드·채팅 입력줄, iOS 키보드

고친 것: 대화방 헤더가 상대 문서 로딩 중 잠깐 '알 수 없음' 으로 보이던 깜빡임 (`ConversationView.tsx`, 로딩 중엔 이름을 비움)

## 검증 안 된 것

- **iOS 키보드 가림** — 시뮬레이터 패널이 하드웨어 키보드라 화면 키보드가 안 떠서 확인 못 함. iOS 실기기·Apple/Google 실로그인·App Attest 도 미검증. 실기기 빌드(.ipa)는 서명 팀 미정
- **Android 실서버 Google 로그인** — 안드로이드 OAuth 클라이언트(SHA-1)가 없어 실패할 것 ([07 › P0](07-todo.md#p0-출시-차단)). 실기기 설치, Play Integrity(App Check)
- 휴대폰 인증 실제 문자, 실시간 위치공유(시작·갱신·종료), 프로필 수정, 국가 변경, 차단 해제,
  신고 5회 자동 숨김, 게시물 삭제, 슈퍼라이크, 추가 필터 아이템, 만료 정리 스케줄러, 추천 '같은 구/시·도' 범위·다음 페이지
- 화면(웹): 사진 선택 창은 자동화 불가라 JS 로 주입해 확인 — 실제 선택 창·탈퇴 버튼은 Android 에서 확인
- 브라우저 패널 제약: 제 클릭으로 연 로그인 팝업과 위치 권한은 막힌다 → 그 단계는 사람이 직접
