## 메뉴

| 메뉴 | 내용 | 코드 |
|---|---|---|
| 대화 | 추천(거리 버킷·필터) + 대화 목록. 데스크톱은 목록 \| 대화방·프로필 2분할 | `app/(main)/chat/`, `src/features/{discover,chat}` |
| 지도 | 구(區) 단위 인원 마커. 개인 좌표는 표시 안 함. 다크는 meesae 다크 | `src/features/map` |
| 피드 | 게시물·좋아요·댓글 + 포인트 허브 탭 | `src/features/{feed,points}` |

화면 폭 ≥ 768 이면 왼쪽 사이드바 + 분할 화면, 아니면 하단 탭 (`src/ui/layout/useLayoutMode.ts`).

## 로그인과 권한

- 로그인: Google / Apple (지금 실서버에서 켜진 건 Google 만)
- 휴대폰 인증 = **추가 권한**: 채팅 사진, 실시간 위치공유, 인증 배지
- 권한 표: `shared/permissions.ts` 의 `MATRIX` (UI·서버·Rules 공통 기준)

## 포인트 정책

숫자는 전부 `shared/economy.ts` 의 `ECONOMY` 한 곳. 운영 중엔 Firestore `config/economy` 로 덮어쓴다.

| 항목 | 값 |
|---|---|
| 첫 대화(intro) | 계정당 10회 무료, 이후 30P |
| 좋아요 | 하루 3회 무료, 이후 10P |
| 위치 인증 / 출석 | +5P / +10P (하루 1회) |
| 프로필 완성 / 휴대폰 인증 | +50P / +100P (1회) |
| 상점 | 부스트 100P · 슈퍼라이크 30P · 읽음 확인 200P · 추가 필터 150P |
| 하루 경계 | 한국 자정(UTC+9) — 국가별 리셋은 미정 |

## 온보딩 단계

`src/features/onboarding/steps.ts` 배열 하나가 순서·게이지·검증을 정한다. 유효성 규칙은 `shared/onboarding-schema.ts`.

기본 정보(닉네임·생년월일·성별) → 사진 → MBTI → 음주 → 흡연 → 직업 → 학교 → 내 동네(위치) → 국가.
MBTI~학교·위치는 건너뛸 수 있다. 만 18세 미만은 가입 불가.
